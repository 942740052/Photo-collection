# 5.12 开放平台与运维

| 模块信息 | 内容 |
|---------|------|
| **模块编号** | 5.12 |
| **模块名称** | 开放平台与运维 |
| **优先级** | P2-P3（增强功能） |
| **依赖模块** | 5.2（安全与访问控制 — API 令牌认证）、5.14（通知与消息中心 — 系统告警） |

---

## 模块概述

本模块提供系统的开放接口和运维管理能力，包括 RESTful API、Webhook 事件通知、插件系统、外部库挂载、系统监控和国际化支持。作为系统的"扩展层"，本模块让系统具备可扩展性和可运维性。

---

## 子功能详细说明

### 5.12.1 API 接口

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| RESTful API | 标准化的 RESTful API 设计 | P2 |
| 认证方式 | API Key / OAuth2 / JWT 令牌认证 | P2 |
| 核心 API 端点 | 用户、照片、相册、搜索、上传/下载、元数据、分享 | P2 |
| API 版本管理 | URL 路径版本控制（如 /api/v1/） | P2 |
| API 速率限制 | 可配置的请求速率限制 | P2 |
| API 文档 | OpenAPI/Swagger 规范的在线文档 | P2 |
| API 浏览器 | 内嵌 API 测试工具（类似 Swagger UI） | P3 |

**核心 API 端点规划：**

| 模块 | 端点 | 方法 | 描述 |
|------|------|------|------|
| 用户 | `/api/v1/users` | GET/POST | 用户列表/创建 |
| 用户 | `/api/v1/users/{id}` | GET/PUT/DELETE | 用户详情/修改/删除 |
| 照片 | `/api/v1/photos` | GET/POST | 照片列表/上传 |
| 照片 | `/api/v1/photos/{id}` | GET/PUT/DELETE | 照片详情/修改/删除 |
| 照片 | `/api/v1/photos/{id}/file` | GET | 下载原始文件 |
| 相册 | `/api/v1/albums` | GET/POST | 相册列表/创建 |
| 相册 | `/api/v1/albums/{id}` | GET/PUT/DELETE | 相册详情/修改/删除 |
| 相册 | `/api/v1/albums/{id}/photos` | GET/POST/DELETE | 相册照片管理 |
| 搜索 | `/api/v1/search` | GET | 搜索照片 |
| 标签 | `/api/v1/tags` | GET/POST | 标签列表/创建 |
| 分享 | `/api/v1/shares` | GET/POST | 分享链接列表/创建 |
| 元数据 | `/api/v1/photos/{id}/metadata` | GET/PUT | 照片元数据 |

**用户故事：**

> 作为高级用户，我希望通过 API 接口批量导入已有照片库，以便从其他平台迁移数据。

> 作为开发者，我希望查看在线 API 文档并测试接口，以便快速集成。

**验收标准：**

```gherkin
Scenario: API 照片上传
  Given 用户已获取有效的 API 令牌
  When 用户通过 POST /api/v1/photos 上传一张照片
  Then 系统返回照片 ID 和元数据
  And 照片出现在用户照片列表中

Scenario: API 认证
  Given 用户使用无效的 API 令牌
  When 调用任何 API 端点
  Then 系统返回 401 Unauthorized
  And 响应中包含错误描述
```

### 5.12.2 Webhook 事件通知

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 事件订阅 | 订阅特定类型的事件通知 | P3 |
| 事件类型 | 新上传、新评论、分享访问、系统告警等 | P3 |
| 回调验证 | Webhook 注册时验证回调 URL 可达性 | P3 |
| 重试机制 | 回调失败时自动重试（指数退避） | P3 |
| 事件日志 | 记录 Webhook 发送历史 | P3 |

**支持的事件类型：**

| 事件 | 触发条件 | Payload |
|------|---------|---------|
| photo.uploaded | 新照片上传完成 | 照片 ID、用户 ID、文件名 |
| photo.deleted | 照片被删除 | 照片 ID、删除者 |
| album.created | 相册创建 | 相册 ID、名称 |
| comment.added | 新评论 | 评论内容、照片 ID、评论者 |
| share.accessed | 分享链接被访问 | 分享 ID、访问者 IP |
| user.created | 新用户注册 | 用户 ID、用户名 |
| system.backup_completed | 备份完成 | 备份 ID、大小、耗时 |
| system.storage_warning | 存储空间预警 | 使用量、配额、百分比 |

**用户故事：**

> 作为开发者，我希望订阅"新照片上传"事件，以便在上传完成后自动触发外部备份流程。

> 作为管理员，我希望查看 Webhook 发送日志，以便排查回调失败的问题。

**验收标准：**

```gherkin
Scenario: Webhook 注册与回调
  Given 开发者通过 API 注册了一个 Webhook
  And 订阅了 photo.uploaded 事件
  And 提供了回调 URL
  When 系统验证回调 URL 可达
  Then Webhook 注册成功
  When 有新照片上传完成时
  Then 系统向回调 URL 发送 POST 请求
  And Payload 包含照片 ID、用户 ID、文件名

Scenario: Webhook 回调失败重试
  Given 回调 URL 临时不可用
  When 系统发送 Webhook 回调失败
  Then 系统按指数退避策略自动重试（最多 3 次）
  And 事件日志中记录失败原因和重试次数
```

### 5.12.3 插件系统

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 插件生命周期 | 安装、启用、禁用、卸载 | P3 |
| 插件注册与发现 | 标准化的插件注册机制 | P3 |
| 插件安全隔离 | 沙箱运行，限制插件权限 | P3 |
| 插件 SDK | 提供插件开发工具包 | P3 |
| 插件配置 | 每个插件独立的配置界面 | P3 |
| 插件市场（可选） | 在线插件仓库（需联网） | P3 |

**插件类型规划：**

| 类型 | 说明 | 示例 |
|------|------|------|
| 存储后端插件 | 不同存储引擎适配 | 本地文件系统、S3、WebDAV |
| AI 模型插件 | 自定义分类/识别模型 | 自训练物体识别模型 |
| 导入源插件 | 从其他平台导入 | Google Photos 导入、Lightroom 导入 |
| 导出插件 | 导出到其他平台 | 导出至社交媒体 |
| UI 扩展插件 | 自定义视图/小部件 | 自定义仪表盘小部件 |
| 主题插件 | 自定义界面外观 | 深色主题、自定义品牌色 |

**用户故事：**

> 作为开发者，我希望开发一个自定义 AI 模型插件，以便使用自训练的图像分类模型。

> 作为管理员，我希望通过管理界面安装和管理插件，以便按需扩展系统功能。

**验收标准：**

```gherkin
Scenario: 插件安装与启用
  Given 管理员下载了一个插件包
  When 管理员通过管理界面上传并安装插件
  Then 插件出现在插件列表中
  And 管理员可启用或禁用该插件
  And 禁用后插件功能不可用
  And 启用后插件功能恢复

Scenario: 插件安全隔离
  Given 一个插件尝试访问未授权的系统资源
  Then 沙箱机制阻止该访问
  And 插件运行日志中记录安全事件
```

### 5.12.4 外部工具集成

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| ExifTool 集成 | 使用 ExifTool 进行元数据读写 | P1 |
| 图片处理引擎 | 集成 ImageMagick / libvips 进行图片处理 | P1 |
| CLI 工具 | 命令行工具支持自动化运维 | P2 |
| FFmpeg 集成 | 视频转码和缩略图提取 | P2 |

**用户故事：**

> 作为超级管理员，我希望配置 ExifTool 可执行文件路径，以便系统正确读取和写入照片元数据。

> 作为超级管理员，我希望系统自动检测 FFmpeg 是否可用，以便支持视频文件的转码和缩略图提取。

**验收标准：**

```gherkin
Scenario: ExifTool 集成
  Given 管理员在系统设置中配置了 ExifTool 路径
  When 用户上传一张照片
  Then 系统使用 ExifTool 提取完整的 EXIF/IPTC/XMP 元数据
  And 元数据正确显示在照片详情面板中
  When ExifTool 路径配置错误或不可用
  Then 系统在管理面板中显示警告
  And 使用内置备用方案提取基本元数据

Scenario: FFmpeg 视频处理
  Given 系统检测到 FFmpeg 可用
  When 用户上传一个视频文件
  Then 系统使用 FFmpeg 提取视频缩略图
  And 系统可对视频进行转码以适配 Web 播放
  When FFmpeg 不可用
  Then 视频上传仍然成功
  And 系统提示"视频转码功能不可用"
```

### 5.12.5 外部库挂载

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 只读挂载 | 以只读方式挂载外部文件夹（NAS/本地目录） | P2 |
| 文件索引 | 对挂载的文件夹建立索引 | P2 |
| 增量扫描 | 定期扫描挂载文件夹的新增/变更文件 | P2 |
| 挂载管理 | 管理多个挂载点（添加/移除/配置） | P2 |
| 挂载状态 | 显示挂载点的状态（在线/离线/扫描中） | P2 |

**用户故事：**

> 作为用户，我希望将已有的 NAS 照片文件夹挂载到系统中，以便统一管理而不需要复制文件。

> 作为摄影爱好者，我希望挂载外接硬盘中的 RAW 照片目录，以便在系统中浏览和搜索。

**验收标准：**

```gherkin
Scenario: 外部库挂载
  Given 管理员挂载了 NAS 上的 /photos 目录
  When 系统完成首次扫描
  Then NAS 中的所有照片出现在系统中
  And 照片以只读方式展示（不可删除/编辑原始文件）
  And 用户可以浏览、搜索、添加标签
  When NAS 中新增了照片
  Then 下次增量扫描时新照片出现在系统中
```

### 5.12.6 系统监控与运维

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 系统概览仪表盘 | CPU、内存、磁盘、任务队列等关键指标 | P2 |
| 服务健康检查 | 各微服务运行状态监控 | P2 |
| 存储空间监控 | 存储使用趋势和预警 | P2 |
| 任务队列监控 | 异步任务积压数量和处理速率 | P2 |
| AI 处理监控 | AI 任务队列状态和平均处理时间 | P2 |
| 日志查看 | 系统日志查看和搜索 | P2 |
| 系统信息 | 版本号、运行时间、数据库大小等 | P2 |
| Prometheus 集成 | 暴露 Prometheus 格式的监控指标（可选） | P3 |

**监控指标：**

| 指标 | 告警阈值 | 通知方式 |
|------|---------|---------|
| CPU 使用率 | > 80% 持续 5 分钟 | 站内通知 |
| 内存使用率 | > 85% | 站内通知 |
| 磁盘空间 | < 10% 剩余 | 站内通知 + 邮件 |
| 任务队列积压 | > 1000 个任务 | 站内通知 |
| AI 处理延迟 | > 10 秒/张 | 站内通知 |
| 服务异常 | 任何服务不可用 | 站内通知 + 邮件 |

**用户故事：**

> 作为超级管理员，我希望通过系统监控仪表盘实时查看 CPU、内存、磁盘等关键指标，以便及时发现系统异常。

> 作为超级管理员，我希望在磁盘空间不足时自动收到告警通知，以便及时清理或扩容。

**验收标准：**

```gherkin
Scenario: 系统监控仪表盘
  Given 管理员打开系统监控页面
  Then 显示所有关键指标（CPU、内存、磁盘、任务队列、AI 处理）
  And 指标实时更新
  And 异常指标（超过阈值）高亮显示

Scenario: 存储空间告警
  Given 磁盘剩余空间低于 10%
  Then 系统自动发送站内通知和邮件告警
  And 告警中包含当前使用量和剩余量
  And 管理员可在监控页面查看存储趋势图
```
