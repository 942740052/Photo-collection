# 5.6 搜索与检索

| 模块信息 | 内容 |
|---------|------|
| **模块编号** | 5.6 |
| **模块名称** | 搜索与检索 |
| **优先级** | P0（核心功能） |
| **依赖模块** | 5.13（AI 引擎 — 语义搜索和以图搜图依赖 AI 向量索引） |

---

## 模块概述

本模块提供系统内照片和视频的多维度搜索能力，包括关键词搜索、高级筛选和基于 AI 的图像内容搜索。作为系统的"发现引擎"，本模块确保用户能从数万甚至数十万张照片中快速定位目标内容。

---

## 子功能详细说明

### 5.6.1 关键词搜索

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 全文搜索 | 搜索照片名称、描述、标签、EXIF 信息 | P0 |
| 搜索建议 | 输入时实时显示搜索建议/自动补全 | P1 |
| 搜索历史 | 记录并展示搜索历史（可清除） | P2 |
| 搜索结果排序 | 按相关度、日期、名称排序 | P0 |
| 搜索范围选择 | 可限定搜索范围（全部/当前相册/特定人物/特定标签） | P1 |
| 搜索结果高亮 | 在搜索结果中高亮匹配的关键词 | P1 |
| 搜索结果计数 | 显示搜索结果总数 | P0 |
| 空结果建议 | 搜索无结果时提供优化建议 | P2 |

**搜索索引范围：**

| 索引字段 | 来源 | 说明 |
|---------|------|------|
| 文件名 | 文件系统 | 原始文件名 |
| 描述 | 用户输入 | 照片描述文本 |
| 标签 | 用户 + AI | 手动标签和 AI 自动标签 |
| 人物 | AI 识别 | 人物名称 |
| 地点 | GPS + 地理编码 | 拍摄地点名称 |
| 相机/镜头 | EXIF | 设备型号 |
| 日期 | EXIF | 拍摄日期（可按年/月/日搜索） |

**用户故事：**

> 作为用户，我希望在搜索框中输入"海边"并立即看到匹配的照片，以便快速找到特定内容。

> 作为用户，我希望系统在输入时自动显示搜索建议，以便快速选择而无需输入完整关键词。

**验收标准：**

```gherkin
Scenario: 全文搜索
  Given 系统中存在多张照片
  When 用户在搜索框中输入"海边"
  Then 系统返回文件名、描述、标签中包含"海边"的照片
  And 搜索结果按相关度排序
  And 显示搜索结果总数

Scenario: 搜索建议
  Given 系统中存在标签"风景"、"风景摄影"
  When 用户在搜索框中输入"风景"
  Then 系统实时显示搜索建议："风景"、"风景摄影"
  And 用户点击建议即可执行搜索
```

### 5.6.2 高级筛选

| 筛选维度 | 描述 | 优先级 |
|---------|------|:------:|
| 时间范围 | 日期选择器、相对时间（今天/本周/本月/本年/自定义） | P0 |
| 相机/镜头 | 按相机型号、镜头型号筛选 | P1 |
| 文件类型 | 按文件格式筛选（JPEG/RAW/视频等） | P1 |
| 尺寸范围 | 按分辨率/文件大小范围筛选 | P2 |
| GPS 地理范围 | 地图框选区域筛选 | P1 |
| 标签组合 | 多标签 AND/OR/NOT 逻辑组合 | P0 |
| 评分/收藏 | 按星级评分、收藏状态筛选 | P1 |
| 人物 | 按识别的人物筛选 | P1 |
| 保存筛选条件 | 将常用筛选组合保存为预设 | P2 |
| 筛选条件持久化 | 刷新页面后保留筛选条件 | P1 |

**筛选组合示例：**

| 场景 | 筛选条件 |
|------|---------|
| 找去年用 Canon 拍的风景照 | 时间：2025年 + 相机：Canon + 标签：风景 |
| 找北京的所有人像 | 地点：北京 + 标签：人像 |
| 找 4 星以上的 RAW 文件 | 评分：≥4星 + 文件类型：RAW |
| 找某人在某地的照片 | 人物：张三 + 地点：上海 |

**用户故事：**

> 作为摄影爱好者，我希望按相机型号筛选所有用特定相机拍摄的照片，以便评估不同设备的效果。

> 作为用户，我希望组合多个筛选条件精确查找照片，并将常用组合保存为预设。

**验收标准：**

```gherkin
Scenario: 高级筛选组合
  Given 系统中有大量照片
  When 用户设置筛选条件：时间范围"2025年1月-6月" + 标签"风景" + 相机"Canon EOS R5"
  Then 系统返回同时满足所有条件的照片
  And 显示每个筛选条件的匹配数量
  And 用户可以逐个移除筛选条件

Scenario: 保存筛选预设
  Given 用户设置了复杂的筛选条件组合
  When 用户点击"保存为预设"并命名为"Canon 风景"
  Then 该预设被保存
  And 用户下次可直接选择该预设应用相同筛选
```

### 5.6.3 图像内容搜索

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 自然语言语义搜索 | 输入自然语言描述查找照片（如"去年夏天在海边的日落"） | P1 |
| 以图搜图 | 上传参考图或选择已有照片查找相似照片 | P2 |
| 按颜色搜索 | 按主色调筛选照片 | P2 |
| 按构图搜索 | 按构图特征筛选（如"对称构图""三分法"） | P3 |
| 搜索结果相似度 | 显示搜索结果与查询的相似度百分比 | P2 |

> **依赖说明**：图像内容搜索依赖 [5.13 AI 引擎](./5.13-AI引擎与智能服务.md) 提供的向量索引和嵌入模型。当 AI 引擎不可用时，图像内容搜索功能降级为仅支持关键词搜索。

**用户故事：**

> 作为用户，我希望用自然语言搜索"去年在海边拍的照片"，以便快速找到特定回忆。

> 作为用户，我希望上传一张参考照片查找相似照片，以便找到同一场景的其他角度。

**验收标准：**

```gherkin
Scenario: 自然语言语义搜索
  Given 系统中有多张不同场景的照片
  And AI 引擎已完成向量索引构建
  When 用户输入搜索词"海边日落"
  Then 系统返回包含海边和日落元素的照片
  And 结果按语义相关度排序
  And 每张结果显示相似度百分比

Scenario: 以图搜图
  Given 系统中已有多张照片
  And AI 引擎已完成向量索引构建
  When 用户选择一张照片并点击"查找相似"
  Then 系统返回与该照片视觉相似的照片列表
  And 结果按相似度排序
  And 用户可以调整相似度阈值

Scenario: AI 引擎不可用降级
  Given AI 引擎服务不可用
  When 用户尝试使用自然语言搜索
  Then 系统显示"智能搜索暂时不可用"提示
  And 关键词搜索和高级筛选功能正常可用
```

### 5.6.4 搜索性能要求

| 指标 | 要求 | 测量条件 |
|------|------|---------|
| 关键词搜索 | < 1 秒 | 10 万张照片库 |
| 语义搜索 | < 2 秒 | 10 万张照片库 |
| 搜索建议响应 | < 200ms | 输入时实时返回 |
| 搜索索引更新延迟 | < 5 秒 | 新照片上传后 |
| 高级筛选 | < 1 秒 | 多维度组合筛选 |
| 以图搜图 | < 3 秒 | 10 万张照片库 |

## 模块级用户故事

> 作为摄影爱好者，我希望用自然语言描述想要查找的照片，系统自动理解我的意图并返回匹配结果，无需手动翻找。

> 作为工作室负责人，我希望组合多个筛选条件精确查找项目素材，并保存常用组合以便下次快速使用。

> 作为家庭用户，我希望搜索"宝宝"即可看到所有包含孩子的照片，无论照片是否被打过标签。

---

## 模块级验收标准

```gherkin
Scenario: 多模式搜索
  Given 系统中有 10 万张照片
  When 用户分别使用关键词搜索、高级筛选、自然语言搜索
  Then 三种搜索模式均能在性能要求时间内返回结果
  And 搜索结果准确且按相关度排序
  And 用户可以在搜索结果中进一步筛选

Scenario: 搜索与筛选联动
  Given 用户通过自然语言搜索"海边"得到 500 张结果
  When 用户进一步添加筛选条件"2025年"和"评分≥4星"
  Then 结果缩小为同时满足所有条件的照片
  And 筛选条件可逐个移除
```
