# 5.14 通知与消息中心

| 模块信息 | 内容 |
|---------|------|
| **模块编号** | 5.14 |
| **模块名称** | 通知与消息中心 |
| **优先级** | P2（增强功能） |
| **依赖模块** | 5.1（用户与账户管理 — 通知接收者为用户）、5.10（分享与协作 — 活动通知触发） |

---

## 模块概述

本模块负责系统内所有通知和消息的管理与分发，包括站内通知、邮件通知、通知规则配置和系统公告。作为系统的"消息总线"，本模块为分享协作、安全告警、存储预警、AI 处理完成等多个模块提供统一的通知能力。

---

## 子功能详细说明

### 5.14.1 站内通知

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 通知列表 | 按时间倒序展示所有通知 | P2 |
| 通知详情 | 点击通知查看详情并跳转到相关页面 | P2 |
| 未读标记 | 未读通知显示未读标识和计数 | P2 |
| 全部已读 | 一键将所有通知标记为已读 | P2 |
| 单条已读 | 点击通知后自动标记为已读 | P2 |
| 删除通知 | 删除单条或批量删除通知 | P2 |
| 通知分类 | 按类型分类显示（系统/协作/安全/AI） | P2 |
| 通知铃铛 | 页面顶部通知铃铛图标显示未读数量 | P2 |

**通知类型：**

| 类型 | 图标 | 触发场景 |
|------|------|---------|
| 协作通知 | 👥 | 新评论、@提及、协作者加入、分享被访问 |
| 系统通知 | ⚙️ | 系统更新、维护通知、功能变更 |
| 安全通知 | 🔒 | 登录异常、2FA 启用、密码修改、账户锁定 |
| 存储通知 | 💾 | 存储空间预警、配额超限、备份完成/失败 |
| AI 通知 | 🤖 | AI 处理完成、回忆生成、人物聚类更新 |
| 同步通知 | 🔄 | 同步冲突、同步完成、设备授权 |

**用户故事：**

> 作为用户，我希望在页面顶部看到未读通知数量，点击后查看所有通知详情。

> 作为用户，我希望点击通知后自动跳转到相关页面（如评论通知跳转到照片详情），以便快速处理。

**验收标准：**

```gherkin
Scenario: 站内通知接收与展示
  Given 用户B对用户A的照片添加了评论
  When 用户A登录系统
  Then 通知铃铛显示未读数量（至少 1）
  When 用户A点击铃铛
  Then 显示通知列表
  And 评论通知显示：评论者、评论内容、时间
  When 用户A点击该通知
  Then 跳转到被评论的照片详情页
  And 该通知标记为已读

Scenario: 全部已读
  Given 用户有 5 条未读通知
  When 用户点击"全部已读"
  Then 所有通知标记为已读
  And 铃铛未读计数清零
```

### 5.14.2 邮件通知

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| SMTP 配置 | 管理员配置 SMTP 服务器信息 | P2 |
| 邮件模板 | 可自定义邮件通知的模板 | P2 |
| 邮件发送 | 通过 SMTP 发送邮件通知 | P2 |
| 发送频率控制 | 避免短时间内发送过多邮件（合并/节流） | P2 |
| 发送日志 | 记录邮件发送历史和状态 | P2 |
| 退订链接 | 邮件中包含退订链接 | P2 |

**邮件通知场景：**

| 场景 | 默认启用 | 说明 |
|------|:--------:|------|
| 分享被访问 | 否 | 有人通过分享链接查看了内容 |
| 新评论 | 是 | 有人对你的照片/相册添加了评论 |
| @提及 | 是 | 有人在评论中 @了你 |
| 登录异常 | 是 | 异常 IP/设备登录 |
| 存储空间预警 | 是 | 存储使用超过阈值 |
| 系统更新 | 是 | 系统版本更新 |
| 备份完成 | 否 | 定时备份完成 |
| AI 处理完成 | 否 | 全库 AI 扫描完成 |

> **注意**：由于系统为本地/私有化部署，邮件通知需要配置外部 SMTP 服务器（如企业邮箱、Gmail 等）或本地邮件服务。如未配置 SMTP，邮件通知功能不可用，站内通知不受影响。

**用户故事：**

> 作为超级管理员，我希望配置 SMTP 服务器，以便系统可以发送邮件通知。

> 作为用户，我希望在有人评论我的照片时收到邮件通知，以便及时回复。

**验收标准：**

```gherkin
Scenario: 邮件通知发送
  Given 管理员已配置 SMTP 服务器
  And 用户A启用了"新评论"邮件通知
  When 用户B对用户A的照片添加了评论
  Then 系统通过 SMTP 发送邮件到用户A的邮箱
  And 邮件内容包含评论详情和跳转链接
  And 邮件发送日志中记录发送成功

Scenario: SMTP 未配置降级
  Given 管理员未配置 SMTP 服务器
  When 触发邮件通知
  Then 邮件不发送
  And 站内通知正常显示
  And 管理后台提示"SMTP 未配置，邮件通知不可用"
```

### 5.14.3 通知规则与偏好

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 通知开关 | 全局通知开关（开/关） | P2 |
| 分类开关 | 按通知类型分别开关（协作/安全/存储/AI） | P2 |
| 频率控制 | 即时/每日汇总/每周汇总 | P2 |
| 免打扰时段 | 设置免打扰时段（如 22:00-08:00） | P2 |
| 管理员强制通知 | 管理员可设置不可关闭的通知（如安全告警） | P2 |
| 默认偏好 | 新用户的默认通知偏好 | P2 |

**用户故事：**

> 作为用户，我希望设置免打扰时段为 22:00-08:00，以便夜间不被通知打扰。

> 作为用户，我希望将非紧急通知设为每日汇总，以便减少通知干扰。

**验收标准：**

```gherkin
Scenario: 免打扰时段
  Given 用户设置了免打扰时段 22:00-08:00
  When 当前时间为 23:00
  And 触发了非紧急通知（如新评论）
  Then 通知不立即推送
  And 在 08:00 后推送积压的通知

Scenario: 通知频率控制
  Given 用户将"协作通知"设为"每日汇总"
  When 一天内收到 10 条协作通知
  Then 不发送 10 条单独通知
  And 在每天指定时间发送 1 条汇总通知
```

### 5.14.4 系统公告

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 创建公告 | 管理员创建系统公告（标题、内容、优先级） | P2 |
| 公告展示 | 在用户界面顶部展示未读公告 | P2 |
| 公告确认 | 用户确认已读公告 | P2 |
| 定时公告 | 设置公告的生效时间和过期时间 | P2 |
| 目标用户 | 可选择公告的目标用户（全部/指定角色/指定用户） | P2 |
| 公告历史 | 查看历史公告列表 | P2 |

**公告优先级：**

| 优先级 | 展示方式 | 适用场景 |
|--------|---------|---------|
| 紧急 | 红色横幅，必须确认才能关闭 | 安全漏洞、系统紧急维护 |
| 重要 | 黄色横幅，可关闭 | 系统升级、功能变更 |
| 普通 | 蓝色横幅，可关闭 | 新功能介绍、使用提示 |

**用户故事：**

> 作为超级管理员，我希望发布系统公告通知所有用户即将进行的系统升级。

> 作为用户，我希望在登录时看到系统公告，了解系统的重要变更。

**验收标准：**

```gherkin
Scenario: 系统公告发布
  Given 管理员创建了一条"重要"级别的公告
  And 目标用户为"所有用户"
  When 用户登录系统
  Then 页面顶部显示黄色公告横幅
  And 横幅包含公告标题和内容
  When 用户点击"已读"
  Then 公告横幅消失
  And 下次登录不再显示该公告

Scenario: 定时公告
  Given 管理员创建了一条公告
  And 设置生效时间为明天 10:00
  And 过期时间为明天 18:00
  When 当前时间在生效时间之前
  Then 公告不显示
  When 到达生效时间
  Then 公告开始显示
  When 到达过期时间
  Then 公告自动消失
```

## 模块级用户故事

> 作为用户，我希望通过统一的消息中心管理所有通知（协作、安全、存储、AI），并自定义通知偏好，避免信息过载。

> 作为超级管理员，我希望发布系统公告通知所有用户，并通过邮件通知关键安全事件。

> 作为用户，我希望设置免打扰时段和通知频率，以便在合适的时间接收通知。

---

## 模块级验收标准

```gherkin
Scenario: 通知全链路
  Given 用户A启用了站内通知和邮件通知
  When 多个模块触发通知（评论、存储预警、AI 完成）
  Then 站内通知列表显示所有通知
  And 邮件通知按用户偏好发送
  And 用户可以管理通知（已读、删除、配置偏好）

Scenario: 通知不可用降级
  Given SMTP 未配置
  When 触发需要邮件通知的事件
  Then 站内通知正常显示
  And 邮件不发送
  And 系统日志记录"邮件发送跳过：SMTP 未配置"
```
