# 5.1 用户与账户管理

| 模块信息 | 内容 |
|---------|------|
| **模块编号** | 5.1 |
| **模块名称** | 用户与账户管理 |
| **优先级** | P0（核心基础功能） |
| **依赖模块** | 5.2（安全与访问控制 — 本模块负责用户实体管理，权限规则由 5.2 定义） |

---

## 模块概述

本模块负责系统中用户实体的全生命周期管理，包括用户注册、登录认证、个人资料与偏好设置、以及管理员对用户账户的管理操作。本模块聚焦于"用户是谁"和"用户的基本信息"，不涉及权限控制（由 5.2 安全与访问控制模块统一管理）。

---

## 子功能详细说明

### 5.1.1 用户注册与登录

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 用户名+密码注册 | 支持用户名和密码注册新账户 | P0 |
| 邮箱邀请注册 | 管理员发送邀请码/邀请链接，用户通过邀请完成注册 | P0 |
| 密码登录 | 使用用户名/邮箱 + 密码登录 | P0 |
| 记住登录状态 | 可选"记住我"功能，延长登录有效期 | P0 |
| 修改密码 | 登录后可修改密码，需验证旧密码 | P0 |
| 密码重置 | 通过管理员重置密码（私有化部署无邮件自助重置） | P1 |
| 账户锁定 | 连续登录失败后自动锁定账户（由 5.2 安全模块控制策略） | P1 |

**密码策略要求：**

| 策略项 | 要求 |
|--------|------|
| 最小长度 | 8 位 |
| 复杂度 | 必须包含大小写字母和数字 |
| 过期策略 | 管理员可配置密码过期周期（默认：永不过期） |
| 存储方式 | 使用强哈希算法（如 Argon2id / bcrypt）加盐存储 |
| 历史密码 | 可配置禁止重复使用最近 N 次密码 |

**用户故事：**

> 作为新用户，我希望通过管理员发送的邀请链接注册账户，以便加入系统的使用。

> 作为已注册用户，我希望在登录时选择"记住我"，以便下次打开时无需重新输入密码。

> 作为用户，我希望修改自己的密码，以便定期更新保障账户安全。

**验收标准：**

```gherkin
Scenario: 用户通过邀请链接注册
  Given 管理员已生成一个有效的邀请链接
  When 用户点击邀请链接并填写用户名和密码完成注册
  Then 用户账户创建成功并自动登录
  And 该邀请链接标记为已使用，不可重复使用

Scenario: 密码强度验证
  Given 用户在注册页面输入密码
  When 密码长度小于8位或不包含大小写字母和数字
  Then 系统显示密码强度不足的提示
  And 不允许提交注册表单

Scenario: 修改密码
  Given 用户已登录系统
  When 用户进入"修改密码"页面并输入正确的旧密码和新密码
  Then 密码修改成功
  And 下次登录需使用新密码

Scenario: 密码重置
  Given 用户忘记密码
  When 用户联系管理员请求重置
  And 管理员在后台为该用户生成临时密码
  Then 用户使用临时密码登录后被强制要求设置新密码
```

### 5.1.2 个人资料与偏好设置

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 个人资料编辑 | 修改头像、昵称、个人简介 | P0 |
| 头像上传 | 支持上传自定义头像图片 | P0 |
| 默认语言 | 设置界面显示语言 | P1 |
| 默认时区 | 设置日期时间的显示时区 | P1 |
| 日期格式偏好 | 选择日期显示格式（YYYY-MM-DD / DD/MM/YYYY 等） | P2 |
| 默认上传可见范围 | 设置新上传照片的默认可见性（私有/公开） | P1 |
| 活动状态显示 | 控制是否向其他用户显示在线状态 | P2 |
| 照片显示密度 | 默认的图片墙缩略图大小偏好 | P2 |

**用户故事：**

> 作为用户，我希望修改我的头像和昵称，以便其他协作成员能识别我。

> 作为用户，我希望设置默认上传可见范围为"私有"，以便新上传的照片不会自动对所有人可见。

**验收标准：**

```gherkin
Scenario: 编辑个人资料
  Given 用户已登录
  When 用户上传新头像并修改昵称
  Then 头像和昵称更新成功
  And 在协作相册中其他用户能看到更新后的信息

Scenario: 偏好设置持久化
  Given 用户设置了默认语言为"英文"和默认时区为"UTC+8"
  When 用户下次登录系统
  Then 系统使用用户设置的偏好进行显示
```

### 5.1.3 用户管理（管理员功能）

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 用户列表 | 查看所有注册用户列表（支持搜索和排序） | P0 |
| 创建用户 | 管理员直接创建用户账户（可设置初始密码） | P0 |
| 编辑用户 | 管理员修改用户信息（昵称、状态、角色等） | P0 |
| 禁用/启用用户 | 临时禁用或重新启用用户账户 | P0 |
| 删除用户 | 删除用户及其关联数据（照片可选择保留或一并删除） | P1 |
| 存储配额设置 | 为每个用户设置存储空间上限 | P1 |
| 批量用户导入 | 通过 CSV 文件批量导入用户账户 | P2 |
| 用户活动概览 | 查看用户的基本活动统计（照片数量、存储占用、最后登录时间） | P1 |
| 邀请码管理 | 生成、查看、撤销邀请码/邀请链接 | P0 |

**用户故事：**

> 作为超级管理员，我希望查看所有用户列表并按存储用量排序，以便识别占用空间最多的用户。

> 作为超级管理员，我希望通过 CSV 文件批量导入团队成员，以便快速完成初始用户创建。

> 作为超级管理员，我希望生成邀请链接并发送给新成员，以便他们自行完成注册。

**验收标准：**

```gherkin
Scenario: 管理员创建用户
  Given 管理员已登录
  When 管理员在用户管理页面填写用户名、初始密码并选择角色
  Then 新用户账户创建成功
  And 用户可使用初始密码登录

Scenario: 禁用用户
  Given 管理员禁用了用户B的账户
  When 用户B尝试登录
  Then 系统提示"账户已被禁用"
  And 拒绝登录

Scenario: 删除用户
  Given 管理员删除用户B
  When 选择"同时删除该用户的照片"
  Then 用户B的账户和所有照片被永久删除
  When 选择"保留照片"
  Then 用户B的账户被删除但照片保留在系统中（变为无主资源）
```

### 5.1.4 登出与会话

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 主动登出 | 用户点击"登出"清除登录状态 | P0 |
| 全设备登出 | 用户可一键登出所有设备的会话 | P1 |
| 登出后跳转 | 登出后跳转到登录页面 | P0 |

**用户故事：**

> 作为用户，我希望在公共设备上使用后能一键登出所有设备，防止他人访问我的账户。

**验收标准：**

```gherkin
Scenario: 主动登出
  Given 用户已登录
  When 用户点击"登出"按钮
  Then 当前会话失效
  And 页面跳转到登录页面
  And 用户无法通过浏览器后退访问受保护页面
```

## 模块级用户故事

> 作为系统管理员，我希望通过邀请制管理用户注册，以便控制谁能使用系统。

> 作为家庭用户，我希望每个家庭成员都有独立账户，以便各自管理自己的照片同时共享家庭相册。

> 作为工作室负责人，我希望为团队成员设置不同的存储配额，以便合理分配存储资源。

---

## 模块级验收标准

```gherkin
Scenario: 完整用户生命周期
  Given 管理员生成邀请链接
  When 新用户通过邀请链接注册
  Then 用户可正常登录、修改个人资料、上传照片
  When 管理员禁用该用户
  Then 用户无法登录但数据保留
  When 管理员重新启用
  Then 用户可恢复正常使用

Scenario: 多用户隔离
  Given 系统中存在用户A和用户B
  When 用户A登录系统
  Then 用户A只能看到自己的照片和被分享的内容
  And 无法看到用户B的私有照片
```

```

  ├── 被依赖：5.2 安全与访问控制（权限规则作用于本模块的用户实体）

  ├── 被依赖：5.5 组织与分类（相册归属用户）
  ├── 被依赖：5.10 分享与协作（分享操作关联用户）
  ├── 被依赖：5.11 跨平台同步（同步操作关联用户）
  └── 被依赖：5.14 通知与消息中心（通知接收者为本模块用户）
```

> **注意**：本模块不包含 RBAC 权限定义。角色管理和权限矩阵统一由 [5.2 安全与访问控制](./5.2-安全与访问控制.md) 模块负责。
