# 5.8 媒体编辑

| 模块信息 | 内容 |
|---------|------|
| **模块编号** | 5.8 |
| **模块名称** | 媒体编辑 |
| **优先级** | P1（核心完善功能） |
| **依赖模块** | 5.3（媒体导入与存储 — 编辑作用于存储的文件）、5.4（备份与恢复 — 版本控制由备份模块管理）、5.13（AI 引擎 — AI 编辑能力由 AI 引擎提供） |

---

## 模块概述

本模块提供照片的基础编辑和 AI 增强编辑能力，以及批量编辑操作。所有编辑遵循非破坏性原则，原始文件始终保留，编辑参数另存为版本记录。本模块定位为基础编辑工具，不替代专业修图软件。

---

## 子功能详细说明

### 5.8.1 基础编辑

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 旋转 | 90° 旋转和自由旋转 | P1 |
| 翻转 | 水平/垂直翻转 | P1 |
| 裁剪 | 自由裁剪和预设比例裁剪（1:1、4:3、16:9 等） | P1 |
| 亮度调整 | 调整照片亮度 | P1 |
| 对比度调整 | 调整照片对比度 | P1 |
| 饱和度调整 | 调整色彩饱和度 | P1 |
| 色温调整 | 调整色温（暖色/冷色） | P2 |
| 高光/阴影 | 调整高光和阴影细节 | P2 |
| 滤镜/预设 | 内置滤镜效果（黑白、复古、暖色、冷色等） | P2 |
| 红眼消除 | 自动/手动红眼消除 | P2 |
| 自动增强 | 一键自动优化色彩和曝光 | P1 |
| 直方图 | 显示照片的亮度/RGB 直方图 | P2 |
| 裁剪辅助线 | 三分法、黄金比例等辅助线 | P2 |

**预设裁剪比例：**

| 比例 | 说明 | 适用场景 |
|------|------|---------|
| 自由 | 无约束自由裁剪 | 通用 |
| 1:1 | 正方形 | 社交媒体头像 |
| 4:3 | 标准照片 | 打印 |
| 3:2 | 单反标准比例 | 摄影作品 |
| 16:9 | 宽屏 | 桌面壁纸、视频封面 |
| 9:16 | 竖屏 | 手机壁纸、Stories |

**用户故事：**

> 作为用户，我希望裁剪照片为 16:9 比例并调整亮度和对比度，以便制作桌面壁纸。

> 作为用户，我希望一键自动增强照片色彩，以便快速改善照片效果。

**验收标准：**

```gherkin
Scenario: 裁剪与调色
  Given 用户在编辑器中打开一张照片
  When 用户选择 16:9 裁剪比例并调整区域
  And 调整亮度 +10、对比度 +5、饱和度 +15
  Then 预览实时更新
  And 用户可以对比编辑前后的效果
  And 原始文件未被修改

Scenario: 自动增强
  Given 用户打开一张曝光不足的照片
  When 用户点击"自动增强"
  Then 系统自动优化亮度、对比度和色彩
  And 用户可以接受或撤销自动增强
```

### 5.8.2 非破坏性编辑与版本历史

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 非破坏性编辑 | 保留原始文件，编辑参数另存 | P1 |
| 编辑历史 | 记录每一步编辑操作 | P1 |
| 撤销/重做 | 支持多步撤销和重做 | P1 |
| 版本对比 | 并排对比不同版本 | P2 |
| 版本回滚 | 一键回滚到任意历史版本 | P1 |
| 编辑参数导出 | 导出编辑参数（可用于批量应用） | P2 |

**非破坏性编辑原理：**

```
原始文件（永不修改）
    ↓
编辑参数记录（JSON 格式）
    ├── 裁剪：{ x: 100, y: 50, width: 800, height: 600 }
    ├── 调色：{ brightness: +10, contrast: +5, saturation: +15 }
    └── 滤镜：{ name: "warm", intensity: 0.8 }
    ↓
实时渲染（预览时应用参数）
    ↓
导出（生成新文件时应用参数）
```

**用户故事：**

> 作为用户，我希望编辑照片时原始文件不会被修改，以便随时恢复到原始状态。

> 作为摄影爱好者，我希望查看照片的编辑历史并对比不同版本，以便选择最佳效果。

**验收标准：**

```gherkin
Scenario: 非破坏性编辑
  Given 用户对一张照片进行了裁剪和调色
  When 用户查看该照片的版本历史
  Then 可以看到原始版本和编辑后的版本
  And 用户可以切换回原始版本
  And 原始文件在存储中未被修改

Scenario: 撤销/重做
  Given 用户连续进行了 5 步编辑操作
  When 用户点击"撤销"3 次
  Then 编辑状态回退到第 2 步
  When 用户点击"重做"1 次
  Then 编辑状态前进到第 3 步
```

### 5.8.3 AI 增强编辑

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| AI 去噪 | 自动去除照片中的噪点（高 ISO 拍摄） | P2 |
| AI 锐化 | 智能锐化模糊区域 | P2 |
| AI 背景虚化 | 自动识别主体并虚化背景 | P2 |
| AI 裁剪建议 | AI 分析构图并建议最佳裁剪区域 | P2 |
| 智能滤镜 | 基于照片内容推荐合适的滤镜 | P2 |
| AI 红眼消除 | 智能检测并消除红眼 | P2 |
| AI 色彩校正 | 自动校正白平衡和色彩偏差 | P2 |

> **依赖说明**：AI 增强编辑功能依赖 [5.13 AI 引擎](./5.13-AI引擎与智能服务.md) 提供的 AI 模型推理能力。当 AI 引擎不可用时，AI 编辑功能降级为仅支持基础编辑。

**用户故事：**

> 作为摄影爱好者，我希望使用 AI 去噪功能处理高 ISO 拍摄的夜景照片，以便获得更干净的画质。

> 作为用户，我希望 AI 自动推荐适合当前照片的滤镜，以便快速美化照片。

**验收标准：**

```gherkin
Scenario: AI 去噪
  Given 用户打开一张高 ISO 拍摄的夜景照片
  When 用户点击"AI 去噪"
  Then AI 引擎分析照片并去除噪点
  And 处理后的照片更干净但保留细节
  And 用户可以对比去噪前后的效果
  And 可以接受或撤销 AI 去噪

Scenario: AI 不可用降级
  Given AI 引擎服务不可用
  When 用户打开编辑器
  Then 基础编辑功能（裁剪、旋转、调色）正常可用
  And AI 编辑按钮显示"暂时不可用"状态
  And 提示用户"AI 功能需要 AI 引擎运行"
```

### 5.8.4 批量编辑操作

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 批量旋转 | 选中多张照片批量旋转 | P1 |
| 批量裁剪 | 选中多张照片应用相同裁剪比例 | P2 |
| 批量调色 | 选中多张照片应用相同的亮度/对比度/饱和度调整 | P2 |
| 批量添加标签 | 选中多张照片批量添加标签 | P1 |
| 批量应用滤镜 | 选中多张照片应用相同滤镜 | P2 |
| 批量应用预设 | 选中多张照片应用相同的编辑预设 | P2 |
| 操作确认 | 批量操作前显示确认对话框（含影响范围） | P1 |
| 进度显示 | 批量操作时显示进度 | P1 |
| 批量操作撤销 | 支持撤销最近的批量操作 | P2 |

**用户故事：**

> 作为摄影爱好者，我希望选中多张照片并批量应用相同的调色参数，以便快速统一风格。

> 作为用户，我希望批量旋转多张方向错误的照片，以便一次性修正。

**验收标准：**

```gherkin
Scenario: 批量调色
  Given 用户选中 50 张照片
  When 用户调整亮度 +10、对比度 +5
  And 点击"应用到所有选中照片"
  Then 系统显示确认对话框"将修改 50 张照片，是否继续？"
  And 用户确认后批量应用编辑参数
  And 显示编辑进度
  And 每张照片保留原始版本

Scenario: 批量操作撤销
  Given 用户对 50 张照片批量应用了调色
  When 用户点击"撤销批量操作"
  Then 所有 50 张照片恢复到编辑前的状态
```

## 模块级用户故事

> 作为摄影爱好者，我希望在非破坏性编辑器中精细调整照片，并使用 AI 去噪和智能滤镜增强画质，同时保留所有编辑历史以便随时回退。

> 作为家庭用户，我希望一键自动增强照片效果，无需专业修图知识也能获得不错的照片效果。

> 作为工作室负责人，我希望批量对项目照片应用统一的调色预设，以便保持品牌视觉一致性。

---

## 模块级验收标准

```gherkin
Scenario: 完整编辑流程
  Given 用户打开一张照片进行编辑
  When 用户依次进行裁剪、调色、添加滤镜
  Then 每步操作都有预览
  And 编辑历史记录完整
  And 原始文件未被修改
  And 用户可以撤销所有操作回到原始状态
  And 用户可以导出编辑后的版本

Scenario: AI 编辑与基础编辑协同
  Given 用户对一张照片先进行了 AI 去噪
  When 用户进一步手动调整亮度
  Then AI 去噪和手动调整的效果叠加
  And 编辑历史中记录了两步操作
  And 用户可以分别撤销每一步
```
