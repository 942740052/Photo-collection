# 5.7 浏览与展示

| 模块信息 | 内容 |
|---------|------|
| **模块编号** | 5.7 |
| **模块名称** | 浏览与展示 |
| **优先级** | P0（核心功能） |
| **依赖模块** | 5.3（媒体导入与存储 — 缩略图由本模块生成）、5.5（组织与分类 — 相册/标签用于浏览）、5.13（AI 引擎 — 回忆功能依赖 AI） |

---

## 模块概述

本模块负责照片和视频的多种浏览视图和展示方式，包括图片墙、时间轴、地图视图、全屏幻灯片、缩略图懒加载、照片详情面板，以及 Live Photos、360°/全景照片和回忆功能等增强展示能力。

---

## 子功能详细说明

### 5.7.1 图片墙视图（Grid View）

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 可调节网格密度 | 小/中/大缩略图切换 | P0 |
| 无限滚动 | 向下滚动自动加载更多照片 | P0 |
| 分页加载（可选） | 支持分页模式替代无限滚动 | P2 |
| 照片信息悬浮 | 鼠标悬浮显示照片基本信息（日期、标签、尺寸） | P1 |
| 多选模式 | 支持框选/点击多选照片 | P0 |
| 排序方式 | 按上传时间、拍摄时间、名称、大小排序 | P0 |
| 堆叠显示 | 堆叠的照片显示为单个卡片+数量标识 | P1 |

**用户故事：**

> 作为用户，我希望在图片墙中自由切换缩略图大小，以便在不同场景下获得最佳浏览体验。

> 作为用户，我希望在图片墙中通过框选快速多选照片，以便批量操作。

**验收标准：**

```gherkin
Scenario: 图片墙网格密度切换
  Given 用户在图片墙视图中浏览照片
  When 用户切换网格密度为"大"
  Then 缩略图以更大尺寸展示
  And 切换过程流畅无闪烁
  And 用户的选择状态保持不变

Scenario: 图片墙多选
  Given 用户在图片墙视图中
  When 用户按住鼠标拖拽进行框选
  Then 框选区域内的照片被选中
  And 选中照片显示选中标识
  And 用户可对选中照片执行批量操作（删除、添加到相册、打标签）
```

### 5.7.2 时间轴视图（Timeline View）

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 按日期分组 | 照片按拍摄日期分组展示 | P0 |
| 层级折叠 | 年/月/日层级可折叠展开 | P0 |
| 事件标注 | 在时间轴上标注重要事件（可自定义） | P2 |
| "回忆"功能 | 展示"N年前的今天"的照片 | P1 |
| 日期跳转 | 快速跳转到指定日期 | P1 |
| 时间轴统计 | 每个时间段显示照片数量 | P1 |

**用户故事：**

> 作为家庭用户，我希望在时间轴视图中按年/月/日层级浏览照片，以便快速找到特定时期的回忆。

> 作为用户，我希望快速跳转到某个日期，以便查看那天拍摄的照片。

**验收标准：**

```gherkin
Scenario: 时间轴按日期分组
  Given 系统中有多张不同日期拍摄的照片
  When 用户切换到时间轴视图
  Then 照片按拍摄日期分组展示
  And 显示"年 > 月 > 日"的层级结构
  And 每个时间段显示照片数量
  And 用户可折叠/展开各层级

Scenario: 日期跳转
  Given 用户在时间轴视图中
  When 用户使用日期选择器跳转到 2025 年 8 月 15 日
  Then 时间轴自动滚动到该日期
  And 展示该日期拍摄的所有照片
```

### 5.7.3 地图视图（Map View）

| 功能 | 描述 | 优先级 |
|------|------|:------:|

| 地图搜索 | 在地图上搜索地点名称 | P2 |

**用户故事：**

> 作为摄影爱好者，我希望在地图上查看所有照片的拍摄地点分布，以便回顾旅行足迹。

> 作为用户，我希望点击地图上的聚合标记查看该位置的照片，以便按地点浏览。

**验收标准：**

```gherkin
Scenario: 地图视图照片分布
  Given 系统中有多张包含 GPS 信息的照片
  When 用户切换到地图视图

Scenario: 无 GPS 照片处理
  Given 系统中存在没有 GPS 信息的照片
  When 用户在地图视图中浏览
```

### 5.7.4 全屏幻灯片

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 全屏浏览 | 照片全屏展示 | P0 |
| 自动播放 | 可配置播放间隔（1-10 秒） | P0 |
| 过渡动画 | 淡入淡出、滑动、缩放等过渡效果 | P1 |

| 幻灯片顺序 | 按日期/随机/自定义排序 | P1 |

**用户故事：**

> 作为用户，我希望以全屏幻灯片模式播放相册中的照片，并配置播放间隔和过渡效果，以便与家人一起回顾。

> 作为用户，我希望在幻灯片播放中快速收藏或分享当前照片，以便不必退出幻灯片。

**验收标准：**

```gherkin
Scenario: 全屏幻灯片播放
  Given 用户在相册浏览页面
  When 用户点击全屏幻灯片按钮
  Then 照片以全屏模式展示
  And 按配置间隔自动切换
  And 过渡动画流畅
  And 用户可随时暂停/继续或退出

Scenario: 幻灯片内快捷操作
  Given 用户正在播放幻灯片
  When 用户点击收藏按钮
  Then 当前照片被收藏
  And 幻灯片继续播放不中断
```

### 5.7.5 缩略图与懒加载

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 多尺寸缩略图 | 生成小/中/大三种尺寸的缩略图 | P0 |
| 虚拟滚动 | 仅渲染可视区域内的缩略图 | P0 |
| 懒加载 | 滚动到可视区域时才加载图片 | P0 |
| 缩略图缓存 | 客户端 + 服务端双层缓存 | P0 |
| RAW 快速预览 | 从 RAW 文件中提取内嵌 JPEG 作为预览 | P1 |
| 渐进式加载 | 先加载低质量占位图，再加载高清版本 | P1 |

**缩略图尺寸规格：**

| 尺寸类型 | 长边最大值 | 用途 |
|---------|----------|------|
| 小缩略图 | 150px | 图片墙密集模式 |
| 中缩略图 | 400px | 图片墙标准模式、相册封面 |
| 大缩略图 | 1200px | 照片详情预览 |
| 预览图 | 1920px | 高清预览（可选） |

**用户故事：**

> 作为用户，我希望浏览大量照片时页面流畅无卡顿，即使相册中有上万张照片。

> 作为摄影爱好者，我希望系统支持 RAW 文件的快速预览，以便不必等待完整解码。

**验收标准：**

```gherkin
Scenario: 缩略图懒加载
  Given 用户浏览包含 10000 张照片的相册
  When 页面初始加载
  Then 仅加载可视区域内的缩略图
  And 用户向下滚动时自动加载更多
  And 页面保持流畅（FPS > 30）

Scenario: RAW 快速预览
  Given 用户上传了一张 RAW 格式照片
  When 系统处理完成
  Then 从 RAW 文件中提取内嵌 JPEG 作为预览图
  And 用户在图片墙中可快速浏览预览
```

```gherkin
Scenario: 照片详情展示
```

```gherkin
Scenario: Live Photo 播放

Scenario: Motion Photo 识别
```

### 5.7.9 回忆 Memories

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 往年今日 | 展示"N年前的今天"拍摄的照片 | P1 |
| 主题回忆 | 基于地点/人物/标签自动生成主题回忆 | P1 |
| 回忆影片 | 自动将回忆照片生成幻灯片影片（可选配音乐） | P2 |
| 回忆编辑 | 用户可编辑回忆内容（添加/移除照片、更换封面） | P2 |
| 回忆分享 | 分享回忆给其他用户 | P2 |
| 回忆通知 | 定期推送"今日回忆"通知 | P2 |

> **依赖说明**：回忆功能依赖 [5.13 AI 引擎](./5.13-AI引擎与智能服务.md) 提供的智能聚类和主题生成能力。

**用户故事：**

> 作为家庭用户，我希望每天打开系统时看到"N年前的今天"的照片，以便回顾美好回忆。

> 作为用户，我希望系统自动生成"去年夏天旅行"的主题回忆，并可以编辑和分享。

**验收标准：**

```gherkin
Scenario: 往年今日
  Given 今天是 2026 年 4 月 9 日
  And 系统中有 2025 年 4 月 9 日拍摄的照片
  When 用户打开"回忆"页面
  Then 显示"1 年前的今天"的照片
  And 用户可以浏览和分享这些回忆

Scenario: 主题回忆生成
  Given 系统中有大量照片
  When AI 引擎分析完成并生成主题回忆
  Then 回忆列表中显示"去年夏天的旅行"等主题
  And 每个回忆包含封面和照片数量
  And 用户可以点击进入回忆查看所有照片
```
