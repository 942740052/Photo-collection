# 5.10 分享与协作

| 模块信息 | 内容 |
|---------|------|
| **模块编号** | 5.10 |
| **模块名称** | 分享与协作 |
| **优先级** | P1（核心完善功能） |
| **依赖模块** | 5.1（用户与账户管理 — 协作者为系统用户）、5.2（安全与访问控制 — 分享权限验证）、5.14（通知与消息中心 — 活动通知） |

---

## 模块概述

本模块负责照片和相册的分享与多人协作功能，包括分享链接生成、协作相册管理、评论系统、活动流和公开画廊。作为系统的"社交层"，本模块让用户能安全地与他人分享照片并协同管理内容。

---

## 子功能详细说明

### 5.10.1 分享链接

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 生成分享链接 | 为单张照片或相册生成带 token 的分享链接 | P1 |
| 密码保护 | 为分享链接设置访问密码 | P1 |
| 有效期设置 | 设置链接过期时间（1天/7天/30天/永久/自定义） | P1 |
| 访问次数限制 | 限制链接最大访问次数 | P2 |
| 分享范围 | 单张照片 / 相册 / 自定义选集 | P1 |
| 下载权限控制 | 控制访问者是否可下载原始文件 | P1 |
| 链接管理 | 查看、撤销、续期已创建的分享链接 | P1 |
| 访问统计 | 查看分享链接的访问次数和访问者信息 | P2 |
| 分享预览 | 分享前预览访客将看到的内容 | P2 |

**用户故事：**

> 作为标准用户，我希望为相册生成一个带密码和有效期的分享链接，以便安全地与朋友分享旅行照片。

> 作为用户，我希望查看分享链接的访问统计，以便了解谁查看了我分享的内容。

**验收标准：**

```gherkin
Scenario: 分享链接生成与访问
  Given 用户为一个相册生成了分享链接
  And 设置了密码保护和7天有效期
  When 访客通过该链接访问
  Then 系统要求输入密码
  And 验证通过后可浏览相册内容
  And 7天后链接自动失效

Scenario: 分享链接权限控制
  Given 用户创建了一个不允许下载的分享链接
  When 访客通过链接浏览照片
  Then 访客可以查看照片但不能下载
  And 下载按钮不显示或显示为禁用状态

Scenario: 分享链接撤销
  Given 用户创建了一个分享链接
  When 用户在链接管理中撤销该链接
  Then 该链接立即失效
  And 访客通过该链接访问时显示"链接已失效"
```

### 5.10.2 协作相册

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 邀请协作 | 邀请系统内用户参与相册协作 | P1 |
| 邀请链接 | 生成协作邀请链接（需系统内用户接受） | P1 |
| 协作者权限 | 查看/上传/编辑/管理四级权限 | P1 |
| 协作者列表 | 查看相册的所有协作者及其权限 | P1 |
| 移除协作者 | 移除协作者的访问权限 | P1 |
| 协作活动通知 | 新上传、评论、修改时通知协作成员 | P2 |
| 协作版本冲突 | 多人同时编辑时的冲突提示 | P2 |

**协作者权限级别：**

| 权限 | 查看 | 上传 | 编辑（修改元数据/标签） | 管理（邀请/移除协作者） |
|------|:----:|:----:|:---------------------:|:---------------------:|
| 查看者 | ✅ | ❌ | ❌ | ❌ |
| 上传者 | ✅ | ✅ | ❌ | ❌ |
| 编辑者 | ✅ | ✅ | ✅ | ❌ |
| 管理者 | ✅ | ✅ | ✅ | ✅ |

**用户故事：**

> 作为工作室负责人，我希望创建协作相册并邀请团队成员上传照片，以便集中管理项目素材。

> 作为协作者，我希望查看自己在哪些协作相册中有权限，以便快速访问。

**验收标准：**

```gherkin
Scenario: 协作相册权限控制
  Given 用户A创建了协作相册并邀请用户B（权限：上传）
  When 用户B尝试删除相册中的照片
  Then 系统拒绝操作并提示权限不足
  When 用户B上传新照片
  Then 上传成功

Scenario: 移除协作者
  Given 用户A从协作相册中移除了用户B
  Then 用户B无法再访问该相册
  And 用户B已上传的照片保留在相册中
```

### 5.10.3 评论系统

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 添加评论 | 对照片或相册添加文字评论 | P2 |
| 回复评论 | 对已有评论进行回复 | P2 |
| 删除评论 | 删除自己的评论（管理员可删除任何评论） | P2 |
| 评论通知 | 被评论时通知相关用户 | P2 |
| 评论时间线 | 按时间顺序展示评论 | P2 |
| 评论计数 | 显示照片/相册的评论数量 | P2 |
| @提及 | 在评论中 @其他用户并通知 | P2 |
| 富文本评论 | 支持基础格式（加粗、链接、表情） | P3 |

**用户故事：**

> 作为用户，我希望在协作相册的照片上添加评论，以便与团队成员交流反馈。

> 作为用户，我希望收到他人对我照片评论的通知，以便及时回复。

**验收标准：**

```gherkin
Scenario: 添加评论
  Given 用户A在协作相册中查看一张照片
  When 用户A添加评论"这张光线很好！"
  Then 评论显示在照片下方
  And 相册的评论计数增加
  And 照片所有者收到评论通知

Scenario: @提及通知
  Given 用户A在评论中 @用户B
  Then 用户B收到通知
  And 通知中包含评论内容和跳转链接
```

### 5.10.4 活动流与通知触发

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 活动流 | 展示相册/照片的所有活动记录 | P2 |
| 活动类型 | 上传、评论、标签变更、分享、下载等 | P2 |
| 活动筛选 | 按活动类型、用户、时间筛选 | P2 |
| 通知触发 | 关键活动触发通知（通过 5.14 通知模块） | P2 |
| 活动时间线 | 按时间倒序展示活动 | P2 |

**活动类型：**

| 活动 | 触发条件 | 通知对象 |
|------|---------|---------|
| 新照片上传 | 协作者上传了新照片 | 相册所有协作者 |
| 新评论 | 有人添加了评论 | 照片所有者 + 被提及的用户 |
| 标签变更 | 照片标签被修改 | 照片所有者 |
| 分享访问 | 有人通过分享链接访问 | 分享创建者 |
| 下载 | 有人下载了照片 | 照片所有者 |
| 协作者加入 | 新协作者加入了相册 | 相册所有协作者 |

**用户故事：**

> 作为工作室负责人，我希望查看协作相册的活动流，以便了解团队成员的操作记录。

**验收标准：**

```gherkin
Scenario: 活动流展示
  Given 协作相册中有多个协作者进行了操作
  When 用户查看活动流
  Then 按时间倒序展示所有活动
  And 每条活动显示操作者、操作类型、操作时间和操作对象
  And 用户可以按活动类型筛选
```

### 5.10.5 点赞与反应

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 点赞 | 对照片点赞/取消点赞 | P2 |
| 反应 | 多种反应类型（👍❤️😂😍🎉） | P2 |
| 点赞计数 | 显示照片的点赞/反应数量 | P2 |
| 点赞列表 | 查看点赞/反应的用户列表 | P2 |

**用户故事：**

> 作为用户，我希望对喜欢的照片点赞，以便表达欣赏。

> 作为用户，我希望使用多种表情反应（如❤️、👍）回应照片，以便更丰富地表达感受。

**验收标准：**

```gherkin
Scenario: 点赞照片
  Given 用户A对一张照片点击了❤️反应
  Then 该照片的反应计数增加
  And 用户A的反应显示在反应列表中
  When 用户A再次点击❤️
  Then 反应取消，计数减少
```

### 5.10.6 公开画廊

| 功能 | 描述 | 优先级 |
|------|------|:------:|
| 公开浏览页面 | 可配置的公开照片画廊页面 | P3 |
| 自定义主题 | 画廊页面主题/样式/布局自定义 | P3 |
| 访问密码 | 画廊页面密码保护 | P3 |
| 水印设置 | 公开展示时自动添加水印 | P3 |
| 画廊 SEO | 自定义标题、描述（用于搜索引擎） | P3 |
| 画廊统计 | 访问量、热门照片统计 | P3 |

> **注意**：由于系统为本地/私有化部署，公开画廊功能仅在内网环境中有意义。此功能为可选增强功能。

**用户故事：**

> 作为摄影师，我希望创建一个公开画廊页面展示我的作品集，以便在内网中与同事和客户分享。

> 作为管理员，我希望为公开画廊配置水印，以便保护照片版权。

**验收标准：**

```gherkin
Scenario: 公开画廊创建与访问
  Given 用户创建了一个公开画廊并选择了照片
  And 设置了访问密码
  When 内网用户访问画廊链接
  Then 系统要求输入密码
  And 验证通过后展示画廊页面
  And 照片带有配置的水印

Scenario: 画廊主题自定义
  Given 管理员配置了画廊的自定义主题（布局、颜色）
  When 用户访问画廊页面
  Then 画廊使用配置的主题样式展示
  And 展示效果与预览一致
```

## 模块级用户故事

> 作为标准用户，我希望生成带密码和有效期的分享链接，安全地与朋友分享旅行照片，并查看访问统计。

> 作为工作室负责人，我希望创建协作相册并邀请团队成员，设置不同权限级别，并查看活动流了解团队操作。

> 作为用户，我希望在协作相册中对照片添加评论和点赞，以便与团队成员互动交流。

---

## 模块级验收标准

```gherkin
Scenario: 完整分享与协作流程
  Given 用户A创建了相册并上传了照片
  When 用户A邀请用户B为协作者（权限：编辑者）
  And 用户B上传了新照片并添加了评论
  Then 用户A收到新上传和评论的通知
  And 活动流中记录了所有操作
  When 用户A生成分享链接给访客
  Then 访客可以浏览相册内容
  And 访客的操作受到分享链接权限限制

Scenario: 分享链接安全
  Given 用户创建了一个带密码和7天有效期的分享链接
  When 访客尝试访问
  Then 必须输入正确密码才能浏览
  And 7天后链接自动失效
  And 用户可以随时撤销链接
```
